# Built-in GitHub Repository Insights

For your repositories (like your portfolio repo, PINN research, or backend ledger):

1. Open any repository on GitHub.
2. Click the **Insights** tab at the top.
3. Select **Traffic** from the left sidebar.
4. GitHub will show you:
   * Total views & unique visitors over the last 14 days.
   * Top referrers (e.g., Google, Reddit, LinkedIn).
   * Which specific project files or paths were viewed most.
